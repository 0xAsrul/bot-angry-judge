A short, funny rant about an office printer that has a PhD in refusing to print — written for make.fun's "Angry Judge: The Short Rant Contest". The program writes the rant (388 characters, under the 400-character cap) to `/output/entry.txt`, where a furious judge model reads it two at a time against the other entries and picks the one that lands hardest.

## Run it

```sh
python3 main.py
```
